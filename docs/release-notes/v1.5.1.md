Version 1.5.1 fixes two problems found by installing 1.5.0 and using it in a language other than English. Nothing else changed.

## Fixed

- **Menus failed or filtered wrongly when the interface was not in English.** A menu such as "Send alerts from severity" sent the translated word (for example "baixo") to the program instead of the setting itself ("low"), so adding a notification channel failed with "Input should be 'low', 'medium', 'high' or 'critical'". The rule editor, the rule tuner and the list of people had the same flaw, and so did the severity, status and category filters on the Alerts, Events and Incidents pages. They now send the right value in every language.
- **The desktop app forgot your settings every time it was closed.** The language you chose and the layout you picked on the Overview went back to their defaults at the next start. The window now keeps the same internal address between launches, so it remembers them. (If that address happens to be in use by another program, the app picks a new one and, for that one start, forgets as before.)

## Good to know

- If you had already chosen a language or an Overview layout in 1.5.0, choose it once more; it is then kept.
- Everything listed under "Good to know" in the 1.5.0 notes still applies: the new screens are English only, the installer is unsigned, and sign-in with roles, email, Slack and Discord notifications, journald and macOS collection have not been tried against real services or machines.

## Upgrading

Install over the existing version; your data is kept.
